    load_device_config_file(path) ¶

    Load a device config file into WorkflowDeviceConfig.

    Device configs contain device-level parameters and noise model settings.

    load_model(path) ¶

    Load a persisted model directory created by Model.save.

    load_pulse_config_file(path) ¶

    Load a pulse config file.

    Pulse configs contain gate duration, carrier frequency, readout, and reset pulse parameters. The returned mapping is later merged into WorkflowDeviceConfig.pulse.

    load_solver_config_file(path) ¶

    Load a solver config file into WorkflowSolverConfig.

    The solver config controls the backend model level, runtime engine selection, solver options, and reference-frame settings.

    load_task_config_file(path, *, require_solver_config=True, require_device_config=True, require_analyser_config=True) ¶

    Load a task config file into WorkflowTaskConfig.

    The task config is the workflow-facing entry file that describes targets, input references, optional features, and output policy.

    参数：

    名称 类型 描述 默认
    path str | Path

    Path to a JSON or YAML task config file.

    		 必需
    require_solver_config bool

    Whether input.solver_config must be present when no external override is provided.

    		 True
    require_device_config bool

    Whether input.device_config must be present when no external override is provided.

    		 True

    返回：

    类型 描述
    WorkflowTaskConfig

    Parsed and validated WorkflowTaskConfig.

    load_task_file(path) ¶

    Compatibility alias: load task-config only.

    normalize_device_payload(device) ¶

    Normalize legacy and component-based device payloads for model building.
