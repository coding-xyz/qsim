    		 0.0
    dt float

    Simulation timestep in seconds.

    		 1.0
    engine str

    Optional runtime engine hint stored in SolverSpec.engine.

    		 'qutip'
    model dict[str, Any] | None

    Plain dictionary produced by older model-building paths.

    		 None

    返回：

    ModelSpec
