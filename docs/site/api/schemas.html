    ModelSpec dataclass ¶

    Engine-neutral simulation model specification.

    ModelSpec is the structured boundary between backend lowering and numerical engines. It describes the circuit context, solver request, time grid, frame, physical system, Hamiltonian, noise, readout, and analysis request without depending on a backend-private runtime representation.

    dimension property ¶

    Hilbert-space dimension requested by the system model.

    dt property ¶

    Simulation timestep in seconds.

    solver_mode property ¶

    Normalized solver mode token such as se, me, or sme.

    t_end property ¶

    Simulation end time in seconds.

    __post_init__() ¶

    Normalize string solver shorthands into SolverSpec objects.

    Subsystem structure selected from active components and connections.

    has_structured_signature property ¶

    Whether all key subsystem representation/coupling fields are set.

    from_dict(data) classmethod ¶

    to_dict() ¶

    Return a JSON-safe dictionary representation.

    SystemSpec dataclass ¶

    Engine-neutral physical system description.

    The primary representation is components plus connections. The qubit, cavity, and coupling init-only arguments are migration helpers that synthesize components when older code supplies compact summaries.

    anharmonicity_Hz property ¶

    Per-transmon anharmonicity list in Hz.

    anharmonicity_rad_s property ¶

    Per-transmon anharmonicity list in rad/s.

    cavity_freq_Hz property ¶

    Frequency of the first resonator component in Hz, if present.

    cavity_nmax property ¶

    Fock truncation for the first resonator component, if present.

    cavity_omega_rad_s property ¶

    Angular frequency of the first resonator component in rad/s.

    g_cavity_Hz property ¶

    Coupling strengths in Hz for supported coupling connections.

    g_cavity_rad_s property ¶

    Coupling strengths in rad/s for supported coupling connections.

    lab_frame_qubit_freqs_Hz property ¶

    Compatibility alias for the component qubit frequencies in Hz.

    lab_frame_qubit_omega_rad_s property ¶

    Compatibility alias for component qubit angular frequencies.

    num_qubits property ¶

    Number of transmon components in the system.

    qubit_freqs_Hz property ¶

    Per-transmon frequency list in Hz.

    qubit_omega_rad_s property ¶

    Per-transmon angular frequency list in rad/s.

    transmon_levels property ¶

    Maximum transmon truncation level across quantum components.
